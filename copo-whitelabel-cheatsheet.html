Main tokens — white-label the entire system

The CoPo library is built on Material UI v6 with a custom semantic-token layer. Most components draw from the same small set of variables — a tenant theme really only needs to override the levers below.
For devs: The font-size scale is unusual — _fontSize/1rem resolves to 20 and _fontSize/0.75rem resolves to 16. Reference the named typography tokens, not raw rem math.

Secondary white-label categories

Beyond the 8 main levers, partners can fine-tune these category palettes. Each card shows the live tokens currently in this theme.
